# Portfolio

Sito personale fatto con React e Vite.

I testi, le tappe e i progetti si cambiano in `src/content.js`.

Per provarlo in locale:

```bash
npm install
npm run dev
```

Per pubblicarlo su GitHub Pages: carica i file (senza `node_modules` e `dist`) nel repository `andreagulfo-dev.github.io`, poi in Settings > Pages scegli GitHub Actions come source.
